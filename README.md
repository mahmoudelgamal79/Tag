# TAG

E-commerce website for a clothing brand, built for a real client. I was the main developer, with support from teammates.

## Features

- Storefront: shop, product pages, likes, checkout and order confirmation
- Customer accounts: registration, login, password reset and account page
- Brand and support pages: brand story, FAQ, shipping, returns, size guide, stockists, careers, sustainability, contact, privacy policy and cookie settings
- Admin dashboard (`dashboard/`): products, orders, customers, messages, analytics and settings
- Arabic and English interface (`js/translate.js`)

## Tech

HTML5, CSS3, JavaScript. The guides in `MD/` describe the integration with a Node.js, Express and SQLite backend.

## Project structure

```
dashboard/    admin dashboard
js/           storefront scripts
css/          styles
assets/       images
MD/           setup and integration guides
```
